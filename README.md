# Mini Hook Page Builder

An AI-powered affiliate hook page builder. Quickly create high-converting landing pages that capture emails and drive traffic to your affiliate offers.

## Features

- 🤖 AI-generated hook titles/headlines
- 📧 Email capture before redirect
- 🎨 Beautiful, mobile-responsive pages
- 💾 Save and manage your hook pages
- 🔗 Custom affiliate URL integration
- 📊 Track your pages

## Quick Start

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```
